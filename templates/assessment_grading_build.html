Rubric

Each line is either scored (counts toward the total) or measured (recorded for the record — mass, load, elapsed time, … — but never added up). The total is always just the sum of the scored lines, unless a manual override is set for a student, in which case the override wins. This app never computes a scoring formula — work out this season's rules by hand and enter the result as a scored line or an override. Leave the rubric empty to just record a single score per student.
